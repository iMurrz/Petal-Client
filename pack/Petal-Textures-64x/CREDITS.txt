PETAL TEXTURES 64x — CREDITS AND LICENSING
==========================================

WHAT THIS PACK IS
-----------------
42 block textures and 78 item textures at 64x for Minecraft 1.21.11, in
vanilla-accurate colours. This pack is OPTIONAL: it exists so Petal has a
block and item set of its own if you do not want to install another pack.

If you would rather use Faithful 64x for blocks and items, do not install this
pack at all. Install Faithful instead and put Petal UI 64x Dark above it.


ART IN THIS PACK
----------------
Every texture is original artwork, generated by the scripts in tools/. Nothing
is copied or derived from Faithful, from any other resource pack, or from
Minecraft's own textures.

Colours follow the conventions the game uses — diamond cyan, gold yellow, iron
grey, redstone red and so on — because those are what makes an item readable in
a hotbar. The drawings themselves are original.
