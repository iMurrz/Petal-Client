PETAL UI 64x DARK — CREDITS AND LICENSING
=========================================

WHAT THIS PACK IS
-----------------
Petal UI 64x Dark is a user-interface overlay for Minecraft 1.21.11. It replaces
GUI and HUD textures only: container windows, buttons, sliders, slots, hearts,
hunger, armour, the hotbar, bars, tooltips and toasts.

It contains NO block or item textures. It is designed to sit on top of a base
texture pack, which supplies the blocks and items.


ART IN THIS PACK
----------------
Every texture in this pack is original artwork, generated by the scripts in
tools/ (see the project README). No textures from Faithful, from any other
resource pack, or from Minecraft itself are included or copied here.

Container window layouts (where each slot sits inside a window) follow the
coordinates Minecraft hard-codes for its slots, so that windows line up
correctly. Those are positions only; the artwork drawn at them is original.
