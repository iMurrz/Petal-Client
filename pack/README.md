# Petal 64x

Two packs for **Minecraft 1.21.11**:

| Pack | What it does | Textures |
| --- | --- | --- |
| **Petal UI 64x Dark** | Interface only — every menu, window, HUD element and icon. Near-black with pink accents. | 489 |
| **Petal Textures 64x** | Optional blocks and items in vanilla-accurate colours, if you don't want another pack underneath. | 120 |

## Recommended setup — Faithful underneath

Petal UI is an **overlay**. It carries no blocks or items, so it sits on top of a base pack.

1. Download **Faithful 64x** from <https://faithfulpack.net> (or the Faithful org on Modrinth).
   It isn't bundled here — grab it yourself.
2. Drop both into your resource packs folder:
   - Petal Client: `%APPDATA%\Petal Client\game\instances\petal\resourcepacks`
   - Vanilla: `%APPDATA%\.minecraft\resourcepacks`
3. In **Options → Resource Packs**, order them like this, top to bottom:

```
   Petal UI 64x Dark     <- interface
   Faithful 64x          <- blocks and items
   Default
```

Higher packs win, so Petal supplies the UI and Faithful supplies everything else. That gives you
real Faithful textures, not an imitation of them.

Prefer to stay self-contained? Use **Petal Textures 64x** in Faithful's place instead. Don't enable
both — whichever sits higher wins.

## Licensing, honestly

Faithful's licence (v4, 31 July 2026) does let you use and modify their work, including in resource
packs, so long as you credit them clearly, link <https://faithfulpack.net>, say specifically what you
used, use only what you need, and ship the licence text or a link to it. It also forbids paywalls,
monetised download links, and training AI models on their work — and it asks that a pack which would
be mostly unmodified Faithful textures be shipped as an **overlay** rather than a copy. That last
line is exactly why Petal UI is built this way.

Worth being clear about one thing: a credit line on its own is not permission. It satisfies a licence
that already grants permission. Here Faithful's licence does grant it, and `CREDITS.txt` in each pack
records the credit, the link and the terms.

Every texture in both packs is original art, generated by the scripts in `tools/`. Nothing is copied
from Faithful, from any other pack, or from Minecraft itself.

**Why the full coverage matters.** Petal sits above a base pack. Anywhere Petal doesn't paint, the
pack underneath shows its own interface — so a half-covered overlay gives you a dark inventory next
to a light recipe book. Petal now covers every screen you actually open.

**Left to the base pack on purpose (34 textures):** hanging-sign backgrounds, Realms promo art, the
world-preset icon, and the title-screen logo and panorama. Those are artwork rather than chrome, and
Petal Client draws its own title screen anyway.

**The look.** Panels are near-black (`#15111E` over `#0A0710`), wells sink to `#0D0A13`, and pink does
the signalling: `#E8248B` accent line across every window, `#FF4FA3` for selection and progress,
`#FF9ACF` for hover. Purple `#8B5CF6` is secondary; mint `#8FF5D2` stays on the XP bar.

**Slot alignment.** Minecraft hard-codes where slots sit inside each window. `tools/extract_layout.py`
reads those coordinates into `tools/container_layout.json`, and the painter draws Petal's own panels
and wells at exactly those positions — geometry only, art original.

## Rebuilding

```bash
cd pack
python3 tools/extract_layout.py   # only if vanilla layouts change
python3 tools/gen_gui.py          # core GUI sprites
python3 tools/gen_gui_extra.py    # advancements, recipe book, lists, icons
python3 tools/gen_containers.py   # container windows
python3 tools/gen_slot_icons.py   # empty-slot icons
python3 tools/gen_blocks.py       # optional pack: blocks
python3 tools/gen_items.py        # optional pack: items
```

Needs Python with Pillow. The UI palette and the material table both live in `tools/petal_paint.py`,
so one edit recolours everything. Tools and armour are 16×16 ASCII maps in `tools/gen_items.py`.
